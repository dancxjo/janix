2026-01-18 – [Logging Allocations] Learning: Logging in the kernel was allocating multiple Strings per event, putting pressure on the allocator in hot paths. Guardrail: Use `SymbolShell::Static` and `&'static str` for metadata that is known to be static.
2026-01-29 – [Syscall Allocations] Learning: Syscall handlers returning variable-sized data often default to heap-allocating `Vec`s, causing allocator churn even for small, frequent requests. Guardrail: Implement hybrid stack/heap buffers (e.g., 1KB stack buffer) in handlers like `Query` and `WatchNext` to handle the common case without allocation.
2026-02-01 – [Build-Time Configuration] Learning: Build-time configurations (e.g., locale) can be injected into the boot image as files (boot modules) via `xtask`, allowing userspace applications to read them without recompilation. Guardrail: Ensure configuration files are explicitly added to both the ISO/HDD filesystem and the Limine bootloader configuration.
